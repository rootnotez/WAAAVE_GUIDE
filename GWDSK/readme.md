## Media Player
On MacOs the default media directory is:  
  `/Applications/waaave_pool_dsk-1_1/data/movies`  
On Windows the default media directory is:  
  `C:/Gravity_Waaaves_v1.19\bin\data`

## Needs Research

TouchDesigner

Webcamoid: Open‑source, cross‑platform suite that supports using local files and network streams as capture sources and includes a built‑in virtual webcam for Windows, macOS, and Linux. It’s designed for easy scene/effect setup, and its virtual camera lets other apps see your processed output.

SplitCam: Windows app that can add video files, slideshows, desktop capture, and more to scenes, and exposes the “SplitCam Video Driver” virtual webcam for use in browsers and conferencing tools. It’s also built to split/share the same camera to multiple apps concurrently without conflicts.

PRISM Live Studio: Desktop studio with a Virtual Camera toggle so other programs can use “PRISM Live Studio” as the camera device, and it supports adding media sources like images/videos to scenes for playback. PRISM Lens can even register multiple independent virtual cameras for flexible setups, with basic effects available for free.
​
ManyCam: Virtual webcam software that supports multiple video sources, adding images/videos as sources, and a Playlist feature to sequence and loop clips for calls or streams. It’s commonly used to route these media sources into conferencing apps via its virtual camera.

​

XSplit Broadcaster: Can function as a virtual camera in Zoom, Google Meet, Teams, and Discord, and supports media slideshows and pre‑recorded videos as scene sources for playout. This makes it straightforward to switch between camera, screen shares, and video clips while sending a single virtual‑cam feed to other apps.
